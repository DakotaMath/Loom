## Learned
- md4c (MIT, CMake) has `MD_FLAG_LATEXMATHSPANS`, which keeps `$…$` and `$$…$$` out of Markdown parsing and writes them as `<x-equation>` elements, so KaTeX can typeset them without `_` and `*` turning into emphasis.
- QScintilla's latest release is still 2.14.1 (GPL v3 or commercial); it ships only qmake files, so Loom needs its own CMake for it.
- Planned rather than verified (for the build issues to confirm on Windows): an open PDF blocks `pdflatex` from rewriting it, and killing `latexmk` alone can leave `pdflatex` running. The spec designs around both.
