## Learned
- CMake's `file(WRITE)` writes `\n` as `\r\n` on Windows, so StatementsCli's `"…\r\n"` body file holds `\r\r\n` there.
- Qt 6's variadic `QString::arg` takes ten arguments in one call, so `%10` needs no second call.
