# 2026-11-05: IDs with their titles, and the ID picker

> **Summary:** Built #37: `LoomCore`'s ID search and statement previews, and in the app the ID picker (from `\ref{`, `\paperref{`, `\cite{`, Ctrl+Space, the form fields and Ctrl+P), titles under every line that mentions IDs, red underlines for IDs that name nothing, hover cards with the compiled preview, and Ctrl+click to open.

**Session model:** Opus 5.5
**Issues and PRs:** #37, PR #48

## Done
- `LoomCore/IdSearch`: `IdIndex` (built once per snapshot) ranks statements, proofs, stubs and papers for each field (exact tag or alias, then ID and title, then tags, then body; ties by recently opened, then tag), resolves `\ref`, `\paperref` and `\cite` names, and reads typed IDs; `idMentions()` and `idBeingTyped()` read LaTeX lines. `foldForSearch()` moved here from the app.
- `LoomCore` previews: `composePreview()` (the statement alone, no proofs, header or page number, `\loomoutside` without titles) and `BuildRequest::preview`, kept as `.loom/build/preview/<tag>-<hash>.pdf`.
- `LoomApp`: `IdTools` (the tab's snapshot, picker, hover card and opening), `IdPicker` and `IdCard`, `IdPreviews` (one preview at a time on the Build lane, below other builds, cut to its content), `IdAssist` (each LaTeX editor's picker, annotations, underlines, dwell hover and Ctrl+click). The list's search uses `IdIndex`; chips and list rows show the card on hover; superseded by is a one-chip field with the picker; the New statement and New proof forms get a + (and Ctrl+Space) on their ID fields; Statement → *Go to statement…* (Ctrl+P). `Lane::run` takes a priority.
- A hang Dakota found while trying the build: Loom froze on start on one project with his saved window size. The PDF pane's Fit width (from #36) laid out for ever as its scroll bar came and went; the vertical scroll bar is now always on, with `CompileTests::fitWidthSettlesAtEverySize` (it fails without the fix). Put in this PR at Dakota's request.
- Tests: 11 Catch2 cases (`IdSearchTests`, `PreviewTests`, one `[tex]`), 10 Qt Test functions (`IdTests`, the preview one with TeX). All 355 `ctest` tests pass on Windows, one skipped (the lock-age test, as before).

## Learned
- QScintilla 2.14.1's `annotation(line)` returns a buffer it never filled ([gotcha](../../gotchas/qt/qscintilla-annotation-returns-garbage.md)).
- `QTest::mouseMove` doesn't start Scintilla's dwell timer here; tests emit `SCN_DWELLSTART` ([gotcha](../../gotchas/qt/qscintilla-dwell-needs-a-real-pointer.md)).
- `QsciStyle(-1, …)` takes a style number from a process-wide counter that has about 24 numbers in all (63 down to 40): one shared style for every editor's annotations, never one per editor.
- A `Qt::Popup` parented to the main window is blocked while a modal form is open: the picker is parented to the form's window then.
- Fit width in `QPdfView` hangs at some sizes when its scroll bar comes and goes ([gotcha](../../gotchas/qt/qpdfview-fit-width-scrollbar-loop.md)). With no debugger here, a 100-line dbghelp sampler on the hung process showed the loop was in Qt; then taking away one saved setting at a time found it.
- M1's validation warns `ref-dangling` for `\ref{4KX7.a}` (a proof ID), though builds label proofs and the spec has the picker offer them (noted in the PR).
