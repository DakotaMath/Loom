## Learned
- toml++ iterates a table in key order, so `[locators]` and renumbering labels are sorted back into file order by each key's line.
- toml++'s `is_array_of_tables()` is false for an empty array ([gotcha](../../gotchas/toml/tomlplusplus-empty-array-not-array-of-tables.md)).
- Renaming a paper moves every file under its folder, so before-and-after problem lists are compared with the old folder's paths mapped to the new one; otherwise every existing problem in a renamed paper would look new and block the rename.
- The spec leaves several small points open (listed under the PR's ⚠️ Flags): `url` in an article's entry, a key used only as another paper's old key, which letter is "next", what `Papers/<Key>/` may hold, and `build-bib`'s exit code and JSON.
