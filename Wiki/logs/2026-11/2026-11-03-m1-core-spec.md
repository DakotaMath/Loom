## Learned
- toml++ keeps tables in a `std::map`, so it can't preserve key order: Loom needs its own writer ([gotcha](../../gotchas/toml/tomlplusplus-sorts-keys.md)).
- toml++'s last tagged release (v3.4.0) is from 2023, but the repo still gets fixes (commits on 2026-11-01), so the spec pins a commit.
- CMake added the `Visual Studio 18 2026` generator in 4.2. GitHub's `windows-latest` is now `windows-2025-vs2026`, and `ubuntu-latest` is 24.04.
- Current versions: CMake 4.4.5, Catch2 3.16.1, Qt 6.12.0 and 6.11.1, install-qt-action v4.5.0.
- Linking Qt Core into `LoomCore` covers SHA-256, Unicode normalisation for the key rule, atomic writes, processes and random numbers, so the core needs no hash library.
