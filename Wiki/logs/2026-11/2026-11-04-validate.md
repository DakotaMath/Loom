## Learned
- In a pre-commit hook, `git commit <paths>` stages into a temporary index and passes it as `GIT_INDEX_FILE`; `loom validate --staged` must keep git's environment as it finds it, unlike `new-project`, which strips git's location variables. Checked by hand: `git commit -m … Statements/X.tex` with a broken file is refused.
- CMake's `execute_process` decodes output in the console code page on Windows unless given `ENCODING UTF-8` (the gotcha above). And `${ARGN}` splits as a list in which a `[` (as in JSON) stops `;` from separating elements; read arguments as `ARGV<n>` instead.
- `L`, like `I`, `O` and `U`, isn't in the tag alphabet; made-up tags in fixtures need checking (`L3MA` read as `13MA` on the command line).
