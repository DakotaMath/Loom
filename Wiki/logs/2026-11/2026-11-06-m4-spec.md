## Learned
- Claude Code 2.1.318's `-p` has what jobs need: `--restricted` (no settings files, file tools confined to the working folders, no code-running tools unless named), `--permission-prompts none` with `--permission-mode dontAsk`, `--agents <file>` with `--agent`, `--session-id` and `--resume`, `--max-budget-usd`, `--strict-mcp-config`. It has no `--max-turns`. These flags are checked to exist, not yet to confine a job as the spec says; #58's real-CLI test does that.
- `stream-json` events seen in a real one-line run: `system`/`init` (with `tools`, `agents`, `permissionMode`, `apiKeySource`, `claude_code_version`), `assistant`, `rate_limit_event`, `system`/`post_turn_summary`, `result` (with `total_cost_usd`, `num_turns`, `permission_denials`, `terminal_reason`, `api_error_status`). See the [gotcha](../../gotchas/claude-code/stream-json-needs-verbose.md).
- `claude auth status --json` reports the sign-in without calling a model, so *Check my setup* can use it for free.
- Planned rather than verified: an `ANTHROPIC_API_KEY` in the environment takes precedence over the subscription sign-in, so the spec has Loom remove it from jobs.
