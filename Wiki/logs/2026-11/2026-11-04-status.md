## Learned
- Read literally, the spec's tie-break ("fewest unmet premises, then lowest letter", judged once the proved set is known) explains J3RW as proved by J3RW.a, whose premise H8KD is proved only *through* J3RW.b: a circular explanation. Keeping, for each proved statement, the proof that brought it into the proved set gives the spec's own reading ("H8KD proved (via J3RW.b)"). Growing the set in rounds, each judged against the set as it began, makes that choice independent of the order statements are visited.
- The worked example's check files were written with fingerprints from `loom fingerprint`, so any change to its statement or proof bodies needs new checks; AH3K.a's checks are deliberately of an earlier body.
- The spec's "What a proof gives" names only the agent's `fail`; the Checks rules and verdict table say either counting check's. The code follows the Checks rules (listed under the PR's ⚠️ Flags).
