## Learned
- Catch2 test names with non-ASCII characters (`…`) can't be selected through `ctest -R` on Windows: the name reaches Catch2 in the console code page and matches nothing. Keep test names ASCII.
- A proof whose premise names nothing never gets a fingerprint, so no check of it can count and its statement never reaches "conditional"; `premiseState`'s "isn't a statement" branch is unreachable today.
