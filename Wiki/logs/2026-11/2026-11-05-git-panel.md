# 2026-11-05: Git in LoomCore and the git panel

> **Summary:** Built #39: the git panel's operations in `LoomCore` (`GitOperations`), Catch2-tested on copies of the demo project with a bare remote, and the panel on the right of every tab, Qt-tested.

**Session model:** Opus 5.5
**Issues and PRs:** #39

## Done
- `Source/LoomCore/GitOperations.{h,cpp}`: `readGitState()` (branch, detached `HEAD`, upstream and ahead/behind, remotes, local branches, an operation in progress, changed files from `git status --porcelain=v2 -z`), `fileDiff()`, `commitFiles()` (only the ticked files, through the commit guard; a refusal's `loom validate` lines as problems; files it added are taken out of the index again), `createBranch()`, `switchBranch()` and `pullFastForward()` (both under `.loom/write.lock`), `fetchRemotes()`, `planPush()` and `pushCommits()`. Every refusal of the spec's table, with a stable code. Git runs with `GIT_TERMINAL_PROMPT=0`; every command is returned as a `GitStep` for Output.
- `Source/LoomApp/GitPanel.{h,cpp}`: the panel. Branch, ahead and behind at the top; changed files with tick boxes and a coloured diff on click; the commit message (kept per project; a first line over 72 characters warns); Commit (asks first about ticked files with unsaved edits), Run checks, New branch…, Switch branch…, Fetch, Pull, Push… (lists the commits, then **Push {n} commits**). Fetch, Pull and Push are hidden without a remote; Push without a commit; only Run checks and Fetch while a merge or rebase is in progress.
- `MainWindow`: the panel on the right of every tab; Ctrl+Shift+G and a click on the status bar's branch open it; the branch says *Not on a branch* when `HEAD` is detached; git's commands go to Output's Git channel with their start time; a refused commit's problems to Problems (`BottomPanel::setCommitProblems`, "Not committed: …"), clickable.
- Tests: `GitOperationsTests` (16 cases) and `GitPanelTests` (7 cases).
- Gotchas: [check-ref-format `--branch` expands `@{-1}`](../../gotchas/git/check-ref-format-branch-expands.md); [Git Bash ignores `TZ=America/Chicago`](../../gotchas/windows/git-bash-tz-ignores-iana-names.md).

## Learned
- `git check-ref-format --branch @{-1}` prints the previous branch and exits 0, so the check must also compare the output with the name.
- Pull's "can't fast-forward" is told apart without reading git's English: after the pull fails, `git merge-base --is-ancestor HEAD @{upstream}` exits 1.
- A Qt Test that keeps a `QTreeWidgetItem*` from the Problems list across a snapshot re-read holds a dangling pointer: the list is rebuilt. Wait for the lanes, then find the row.
- On Windows, `TZ=America/Chicago date` gives the UTC date (see the gotcha); this log's date came from plain `date`.
