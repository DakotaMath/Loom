## Learned
- Appending a check as text, rather than rewriting the history, keeps every earlier entry byte for byte, comments included; only the merge driver rewrites in canonical form.
- A multi-line TOML string written with `"""` + LF + text + `"""` reads back exactly, so the writer needs no final line break; the existing `tomlMultilineString()` adds one, which would change a `changes` value on every merge. Hence `tomlMultilineStringAsIs()`.
- `--outdate-checks` runs the edit unconfirmed first and asks Dakota only if it is refused for outdating checks, so the prompt can name the proofs and an edit that outdates nothing needs no click.
- `_isatty()` is true for `NUL` on Windows ([gotcha](../../gotchas/windows/isatty-true-for-nul.md)).
