# Templates: the project kit

What Loom copies into every new research project: the project's `CLAUDE.md`, agent definitions, job prompts, and starter files, in `project/` (M1 for the formats, M4 for jobs). `hooks/pre-commit` is the git hook `loom install-hooks` writes into each project's `.git/hooks/`.

Everything in this folder is dedicated to the public domain under [CC0 1.0](LICENSE), so projects made with Loom carry no licence from it; each project's owner licenses their project however they like.
